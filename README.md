# Unbiased AI News

A website that delivers true, unbiased reporting by aggregating news from leading sources, processing information with advanced AI for bias removal, and publishing radically transparent, fact-based journalism.

## MVP Features
- Aggregates stories from major news organizations (AP, Reuters, BBC, NYT, Fox, CNN, Bloomberg, Al Jazeera, etc.).
- Uses AI to identify and remove bias, focusing on facts, multiple perspectives, omission detection, and editorial choices as outlined in journalism ethics.
- Displays sources, algorithmic explanation, and allows user feedback for continuous improvement.
- Provides full transparency: funding, editorial pipeline, algorithm rules, fact-check methodology.
- Only publishes stories with source links and disclosure if AI detects likely bias.

## Tech Stack Proposal
- Frontend: Next.js, React
- Backend: FastAPI or Node.js
- News source APIs: NewsAPI.org, GNews, NYT, Guardian, Bing News Search, RSS feeds (where available)
- LLM/AI: Gemini, GPT-4, open-source LLMs (bias detection, fact extraction)
